# Dataset Documentation

## Demonstration dataset

This project uses `synthetic_dairy_milk.csv`, an explicitly synthetic, deterministic demonstration dataset generated by `src/data_processing.py`. It is **not** a real dairy-farm dataset and must not be presented as evidence of real-world performance.

- Target: `milk_yield_liters`, daily milk yield in liters per cow per day.
- Observation period: the 305-day lactation period is represented by `days_in_milk`; this is a simulated row, not one real cow-tracing history.
- Features: breed, age in months, lactation number, body weight, daily feed, parity stage, and days in milk.
- Source: generated locally with NumPy's seeded pseudorandom generator.
- License: project-generated demonstration data; no independent source license applies.
- Limitations: relationships are intentionally simplified, no true farm measurements are included, there may be correlation artifacts, and results cannot support biological, commercial, or veterinary conclusions.

The generator is run once with a fixed seed only if the CSV is absent. The application validates required columns, numeric types, ranges, missing values, and duplicate rows before training. Replace this file with a licensed real dataset only after reproducing the documented schema and changing all model claims accordingly.
